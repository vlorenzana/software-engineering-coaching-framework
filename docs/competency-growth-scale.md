# SECAV-O Competency Growth Scale

The competency scale is intended for longitudinal coaching evidence. It is not a universal certification scale.

| Level | Label | Interpretation |
|---|---|---|
| 1 | Observed | Engineer has seen the activity but has not yet demonstrated independent performance. |
| 2 | Assisted | Engineer performs the activity with substantial guidance. |
| 3 | Performs with Review | Engineer performs the activity, but work still requires routine review/correction. |
| 4 | Independent | Engineer performs the activity with acceptable quality and normal oversight. |
| 5 | Can Review Others | Engineer can evaluate others' work against acceptance criteria and provide useful findings. |
| 6 | Can Coach Others | Engineer can guide others, explain tradeoffs, detect recurring patterns, and support competency development. |

## Evidence examples

Evidence supporting a competency level may include:

- reviewed work products;
- peer-review findings;
- formal inspection records;
- test artifacts and results;
- defect patterns;
- architecture/design review records;
- demonstrated handling of AI-assisted work with accountable human validation;
- repeated successful performance across multiple sprints.
