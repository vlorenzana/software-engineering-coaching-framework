# Upload Instructions

This ZIP is structured so that the **contents of this folder** should be uploaded to the root of the GitHub repository.

Target repository:
https://github.com/vlorenzana/software-engineering-coaching-framewor

Recommended steps in the GitHub web interface:

1. Open the repository.
2. Choose **Add file → Upload files**.
3. Drag all files and folders from inside `software-engineering-coaching-framework/`.
4. Use a commit message such as:
   `Initialize SECAV-O framework prototype v0.1.0`
5. Commit directly to `main` for this initial empty repository.

After upload, verify that these paths exist:

- README.md
- ontology/secav-o.ttl
- validation/secav-o.shacl.ttl
- examples/design-review.ttl
- docs/architecture.md
- docs/competency-questions.md
- pilot/pilot-protocol.md
- CHANGELOG.md
- CITATION.cff
- LICENSE

Note: the current GitHub repository name ends in `framewor` rather than `framework`. The ontology namespace and citation file intentionally use the current repository URL so the links remain valid. If the repository is later renamed, update the namespace/base URLs and CITATION.cff.
