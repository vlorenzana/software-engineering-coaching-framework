# CLAUDE.md — Project Instructions

## Language rule

**All content written into the framework must be in English.**

This applies to:
- Ontology terms, labels, and comments (`secav-o.ttl`, extension files)
- SHACL shapes and messages (`*.shacl.ttl`)
- Checklist rows and section text
- Template content
- Guide prose
- Code and file content in general

This rule holds regardless of the language of the source documents or the user's prompts. Input PDFs and conversation prompts may be in Spanish; everything committed to the repository must be in English.
